# Kosmic – AI-Powered Creator Marketplace

## Overview

Kosmic is an AI-powered creator marketplace that connects brands and marketing agencies with suitable video creators.

The platform helps brands discover creators, explore portfolios, generate structured creative briefs, and manage collaboration requests through one platform.

## Problem Statement

Brands and marketing agencies struggle to find suitable video creators, compare their skills and portfolios, and turn marketing goals into clear creative briefs.

Kosmic helps brands discover suitable creators, generate marketing content with AI, and manage collaboration requests through one platform.

## Key Features

- Creator marketplace and discovery
- Creator profiles and portfolio management
- Search creators by niche, skills, AI tools, and content type
- AI-assisted creative brief creation
- Brand and creator collaboration requests
- Application status management
- Portfolio project management
- REST API backend
- SQLite database for data storage
